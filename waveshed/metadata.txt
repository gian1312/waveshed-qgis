about=Waveshed provides RF propagation analysis for QGIS - area coverage (Site Analysis) and point-to-point link budgets - using LOS, Free-Space Path Loss, and ITM (Longley-Rice) models. All computation is performed by the proprietary Aether engine, a separate closed-source GPU binary that is NOT bundled with this plugin. The engine is downloaded on demand from https://waveshed.io through the plugin's Download dialog (an explicit, user-initiated action) and is licensed under its own EULA, shown for acceptance before download. Running analyses additionally requires an API key obtained from https://waveshed.io. Supported engine platforms: Windows x64, Linux x64, and macOS arm64.
